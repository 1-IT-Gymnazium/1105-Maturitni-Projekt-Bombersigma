Atomic BomberSigma - Aktuální souhrn projektu
=============================================

1. Identita projektu
--------------------
Atomic BomberSigma je lokální multiplayer hra ve stylu Bombermana napsaná v Pythonu s použitím Pygame.
Projekt už není jen jednoduchý prototyp s náhodnou mřížkou a bombami, ale má několik navazujících systémů:

- hlavní menu a options menu
- dvoukrokovou předzápasovou konfiguraci
- výběr mapy včetně presetů a random mapy
- konfiguraci počtu hráčů, barev a kláves
- perzistentní ukládání nastavení do JSON souboru
- power-up systém s trvalými i dočasnými efekty
- HUD indikátory aktivních efektů
- build pipeline pro PyInstaller

Kód je rozdělený do menších balíčků:

- `src/game/assets` - konfigurace, asset loadery, zvuky, keybindy, ukládání nastavení
- `src/game/core` - vysoká herní flow logika a přepínání stavů
- `src/game/objects` - herní objekty jako hráč, bomba, tile, grid, power-upy
- `src/game/systems` - vstup, pohyb, bomb logic, preview map
- `src/game/ui` - menu, tlačítka, HUD a nastavovací UI


2. Spouštění a životní cyklus aplikace
--------------------------------------
Hlavní entry point je `src/launch.py`.

Start aplikace probíhá takto:

1. Načtou se runtime settings přes `load_runtime_settings()`.
2. Inicializují se obrázky přes `initialize_images()`.
3. Aplikuje se branding okna přes `cfg.apply_window_branding()`.
4. Inicializují se audio assety přes `initialize_sounds()`.
5. Řízení přebírá `game.core.game_state_manager.run()`.

Je důležité, že nastavení se při ukončení zase uloží. `game_state_manager.run()` má `finally` blok, který vždy zavolá:

- `save_runtime_settings()`
- `pygame.quit()`
- `sys.exit()`

To znamená, že hlasitosti, grid size, vybraná mapa, počet hráčů, odstíny hráčů i keybindy se mezi spuštěními zachovávají.


3. Globální konfigurace a runtime state
---------------------------------------
Soubor `src/game/assets/config.py` funguje jako centrální runtime modul.

Jeho hlavní role:

- zavolá `pygame.init()`
- vytvoří fullscreen `pygame.SCALED` display
- drží logické rozlišení 1920x1080
- vystavuje globální `DISPLAY`, `CLOCK` a `FPS`
- drží grid metriky a přepočítává je podle velikosti mapy
- drží základní gameplay a audio hodnoty

Důležité runtime proměnné:

- `GRID_WIDTH`, `GRID_HEIGHT` - rozměr mřížky
- `TILE_SIZE` - velikost tile v pixelech, odvozená z gridu
- `LOCAL_PLAYERS` - počet lokálních hráčů
- `PLAYER_HUES` - barevné odstíny pro jednotlivé hráče
- `DEFAULT_BOMB_COOLDOWN` - základní cooldown bomby
- `SELECTED_MAP` - jméno vybraného map presetů nebo `"random"`
- `RANDOM_MAP_OBSTACLE_CHANCE` - hustota překážek pro random mapu
- `POWER_UP_DROP_CHANCE` - šance dropu power-upu po zničení překážky
- `MASTER_VOLUME`, `SFX_VOLUME`, `MUSIC_VOLUME` - hlasitosti

Funkce `set_grid_size(size)` omezí velikost gridu na 5 až 14 a přes `refresh_grid_metrics()` dopočítá nové rozměry boardu.


4. Perzistence nastavení
------------------------
Novější a důležitá část projektu je `src/game/assets/settings_store.py`.

Tento modul:

- ukládá settings do `%APPDATA%\\AtomicBomberSigma\\settings.json`
- při absenci `APPDATA` používá uživatelský home adresář
- rozděluje nastavení do dataclass bloků:
  - `AudioSettings`
  - `GameplaySettings`
  - `PlayerSettings`
  - `ControlsSettings`
  - `AppSettings`
- při načítání data sanitizuje a clampuje
- při chybě čtení nebo rozbitém JSONu spadne zpět na runtime defaulty

Persistované oblasti:

- master/SFX/music volume
- velikost gridu
- power-up drop chance
- selected map
- obstacle chance pro random mapu
- počet lokálních hráčů
- odstíny hráčů
- keybindy až pro 4 hráče

Tím pádem už options a pregame volby nejsou čistě dočasné jen pro jedno spuštění.


5. Hlavní stavový tok aplikace
------------------------------
Top-level flow řídí `src/game/core/game_state_manager.py`.

Používá jednoduchou smyčku místo formální scene architektury:

1. `main_menu.run()`
2. `pregame_phase.run()`
3. `game_loop.run()`

Chování návratových hodnot:

- `main_menu.run()` vrací `True`, pokud se má aplikace ukončit
- `pregame_phase.run()` vrací:
  - `True` pro návrat do menu
  - `False` pro pokračování do zápasu
  - `None` pro úplné ukončení
- `game_loop.run()` vrací:
  - `"restart"` pro okamžitý restart match
  - `True` pro quit aplikace
  - `False` pro návrat zpět do outer flow

Restart zápasu obchází znovu hlavní menu i pregame a rovnou spouští další match se současným nastavením.


6. Menu a předzápasová konfigurace
----------------------------------
`src/game/core/main_menu.py` vytváří landing screen s tlačítky:

- Play
- Options
- Quit
- logo bez akce

Menu zároveň spouští hudbu `secret_music` a vykresluje text verze `v.0.4`.

`src/game/core/options_menu.py` je samostatná settings obrazovka se slidery pro:

- master volume
- SFX volume
- music volume
- velikost gridu
- power-up drop chance

Hodnoty se aplikují živě za běhu:

- audio přes `sounds.set_master_volume()`, `set_sfx_volume()`, `set_music_volume()`
- grid přes `cfg.set_grid_size()`
- drop chance přímo do `cfg.POWER_UP_DROP_CHANCE`

`src/game/core/pregame_phase.py` má dvě navazující fáze:

1. `MapSelectionUI`
2. `PlayerCustomizationUI`

Obě fáze sdílí confirm flow. Enter může potvrzení vyvolat i přímo z UI komponenty.


7. Výběr mapy a mapové presety
------------------------------
Výběr map řeší `src/game/ui/map_selection_ui.py`.

Aktuálně jsou dostupné preset mapy z `src/game/objects/grid_preset.py`:

- `sandbox`
- `corners`
- `cross`
- `frame`
- plus speciální volba `random`

`GridPreset` drží malé symbolické patterny, které se škálují na aktuální velikost gridu.
Tokeny:

- `.` = prázdné pole
- `x` = překážka

Preview mapy renderuje `src/game/systems/map_preview.py`.
Ten si pro náhled dočasně vytvoří grid a zmenšeně vykreslí tile sprity. U random mapy se místo klasického preview ukazuje ikona a slider pro obstacle chance.

Potvrzení v `MapSelectionUI.confirm()` uloží výsledek do `cfg.SELECTED_MAP`.


8. Konfigurace hráčů a ovládání
-------------------------------
`src/game/ui/player_customization_ui.py` řeší:

- počet hráčů
- barvy hráčů
- keybindy pro jednotlivé směry a bombu

Limity a pravidla:

- počet hráčů je 2 až 4 v rámci tohoto UI
- keybindy jsou podporované až pro 4 hráče
- odstíny hráčů se vybírají z pevné množiny preset hue hodnot
- aktivní hráči mají mít unikátní barvy

Výchozí keybindy jsou v `src/game/assets/keybinds.py`:

- hráč 1: `WASD` + `Space`
- hráč 2: šipky + `Right Shift`
- hráč 3: `IJKL` varianta + `;`
- hráč 4: numpad varianta

`src/game/systems/input.py` už nepoužívá jen jednoduchý polling. Drží:

- globální `_event_list`
- `_held_directions` pro každého hráče

Při `KEYDOWN` si pamatuje pořadí držených směrů. `check_for_movement_input()` pak preferuje naposledy aktivní směr, který je zrovna průchozí. Díky tomu se pohyb chová lépe při držení více kláves.


9. Generování gridu a spawn logika
----------------------------------
`src/game/objects/grid.py` staví herní mřížku.

`create_grid()` umí dva režimy:

- preset grid přes `GridPreset`
- random grid přes obstacle chance

Každý `Tile` zná svou grid pozici, pixel pozici, obstacle stav, bomb stav, případný power-up a sousedy.

Grid modul navíc obsahuje spawn helpery:

- `tile_has_safe_spawn_axis()`
- `get_spawnable_tiles()`
- `get_tile_at()`
- `clear_tile()`
- `carve_spawn_lane()`

V `game_loop.run()` se grid negeneruje jen jednou naslepo. Match setup:

- zkouší až 40 generací, dokud není dost spawnable polí pro všechny hráče
- když to nevyjde, vybere kandidátní tiles a ručně jim proseká spawn lane

To je významné zlepšení proti dřívějšímu čistě náhodnému přístupu, protože zápas méně často začne v nehratelném layoutu.


10. Hráč, pohyb a runtime efekty
--------------------------------
`src/game/objects/player.py` reprezentuje hráče na boardu.

Player drží:

- `state` (`alive` / `dead`)
- `hue`
- `pos`, `grid_pos`, `target_pos`
- pohybový stav `is_moving`
- `hud`
- čas poslední bomby
- základní a aktuální movement speed
- základní a aktuální bomb cooldown
- základní a aktuální bomb range
- `Effects` komponentu pro power-upy

Pohyb:

- hráč se přesouvá po tilech
- vizuálně se ale mezi tilemi interpoluje po framech
- rychlost pohybu se škáluje podle `TILE_SIZE`

`src/game/systems/movement.py` kontroluje průchodnost cílového tile a při vstupu na tile rovnou sebere power-up, pokud tam je.

Player navíc používá předpočítané hue-shifted sprity, pokud jsou dostupné. To snižuje runtime náročnost při draw/update.


11. Bomba, exploze a power-upy
------------------------------
Bomb systém je rozdělený do:

- `src/game/objects/bomb.py`
- `src/game/systems/bomb_logic.py`

Bomb workflow:

1. Hráč stiskne svou bomb klávesu.
2. `handle_bomb_input()` ověří cooldown a obsazenost tile.
3. Vytvoří se `Bomb`.
4. Bomba odtikává fuse frames.
5. Po explozi se šíří křížem do 4 směrů podle radiusu.
6. Překážka výbuch zastaví, ale předtím ji zničí.
7. Zničená překážka může dropnout power-up.
8. Hráči v zasažených tilech zemřou.

Aktuální power-up drop tabulka:

- `speed_boost`
- `bomb_range_up`
- `bomb_cooldown_reduce`
- `infinite_bombs`

`src/game/objects/powerup.py` zavádí univerzální effect systém:

- `EffectInstance`
- `EffectSpec`
- `Effects`
- `Powerup`

Podporované stacking politiky:

- `refresh`
- `stack`
- `ignore`

Aktuální efekty:

- `speed_boost` - dočasné zrychlení
- `bomb_range_up` - trvalé zvýšení radiusu
- `bomb_cooldown_reduce` - trvalé zkrácení cooldownu
- `infinite_bombs` - dočasný nulový cooldown

Effects se průběžně přepočítávají a po expirování vrací staty hráče na původní hodnoty.


12. HUD, indikátory a další UI komponenty
-----------------------------------------
`src/game/ui/player_hud.py` vykresluje panel hráče s:

- portrétem hráče
- indikátorem bomb cooldownu
- ikonou speed boostu s odpočtem
- stack indikátorem range bonusu
- stack indikátorem cooldown bonusu
- indikátorem infinite bombs

HUD používá pomocné UI prvky:

- `draining_icon.py` pro dočasné efekty s ubývající výplní
- `stacking_icon.py` pro stack count efekty

Další UI moduly:

- `button.py` - klikatelné image buttony
- `settings_ui_elements.py` - slider widget
- `pause_menu.py` - pause overlay s resume/restart/menu flow
- `moving_element.py` - animované elementy pro endgame texty a winner arrow


13. Hlavní match loop
---------------------
`src/game/core/game_loop.py` je centrální orchestrátor zápasu.

Před vstupem do frame loopu připraví:

- pause menu
- endgame animace
- winner text variants podle barvy hráče
- winner arrow variants
- grid
- seznam hráčů
- HUDy hráčů

Potom spustí asynchronní preload hráčských assetů přes `ThreadPoolExecutor`, aby:

- předem přebarvil board sprity
- předem připravil HUD ikony

Každý frame:

1. tick clock
2. načti event queue
3. zpracuj quit a ESC
4. update bomb
5. update input a movement živých hráčů
6. zpracuj bomb input
7. vyhodnoť, kdo přežil
8. vyrenderuj board, hráče, bomby a případný pause/end overlay

Když se hra pauzne:

- otevře se `Pause_menu.pause()`
- po návratu se čas pauzy přičte k:
  - `last_bomb_time`
  - aktivním effect timerům

To zabraňuje tomu, aby cooldowny a boosty ubíhaly během pause.

Endgame:

- 0 živých hráčů => zobrazí se `lose_text`
- 1 živý hráč => zobrazí se barvený `win_text` a winner arrow

Po konci zápasu se existující bomby vyčistí a běží už jen finální animace.


14. Assets a načítání zdrojů
----------------------------
`src/game/assets/graphics.py` načítá všechny obrázky z `src/game/assets/images` do globálního slovníku `images`.
Klíč je lowercase jméno souboru bez přípony.

Modul také poskytuje:

- `resize_image()`
- `rotate_image()`
- `shift_hue()`

`shift_hue()` používá `pygame.surfarray`, `numpy` a `colorsys`, takže přebarvení sprite není jen jednoduchý tint, ale skutečný HSV posun.

`src/game/assets/sounds.py`:

- inicializuje `pygame.mixer`
- načítá sound efekty a music tracky
- vytváří dedikované audio channely
- kombinuje `MASTER_VOLUME` a `SFX/MUSIC_VOLUME`
- podporuje source run i PyInstaller přes `sys._MEIPASS`

Aktuální channely:

- `ui`
- `explosion`
- `gameplay`
- `footsteps`
- `pickup`
- `b_place`
- `death`


15. Build a distribuce
----------------------
Repo obsahuje více `.spec` souborů pro PyInstaller.
Nejdůležitější je `AtomicBomberSigma.spec`.

Ten balí:

- `src/launch.py`
- `src/game/assets/images`
- `src/game/assets/audio`
- `src/game/assets/config.conf`
- `icon.ico`

Asset loadery v `graphics.py` a `sounds.py` umí přepnout cestu podle toho, jestli hra běží ze zdrojáků nebo z PyInstaller bundlu.


16. Aktuální stav architektury
------------------------------
Projekt je stále relativně malý a přímočarý, ale proti starší verzi je výrazně dospělejší.

Hlavní posuny:

- přibylo ukládání a načítání nastavení
- přibyly mapové presety a map preview
- přibylo předzápasové player customization UI
- power-upy jsou už samostatný systém, ne jen jednorázová logika
- HUD umí číst stacky i dočasné efekty
- spawn logika se snaží aktivně zabránit nehratelným startům
- asset preprocessing se částečně přesunul mimo hlavní thread

Výsledkem je projekt, který už není jen tech demo jedné match smyčky, ale menší ucelená hra s konfiguračním flow, persistencí a rozšiřitelnými gameplay systémy.
